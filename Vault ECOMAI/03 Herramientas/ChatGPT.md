# ChatGPT

Asistente de IA de OpenAI usado de punta a punta en el curso: para replicar o crear landings (código Liquid, traducción y edición de imágenes de producto), escribir y dividir guiones de creativos publicitarios en clips, y generar el copy de los anuncios.

🔗 https://chatgpt.com

## Para qué se usa en el curso

- **[[Modulo 3 - Crea tu pagina y tu marca|Módulo 3]]:** Herramienta central del módulo tanto para replicar landings como para crearlas de cero: genera el código Liquid, traduce y adapta textos, genera y edita imágenes del producto, y corrige errores a partir de capturas de pantalla.
- **[[Modulo 4 - Creativos publicitarios|Módulo 4]]:** Usado (con el apodo "Karen") para recibir las reglas de trabajo, dividir el guion en clips, generar la imagen base de cada toma y ajustarla (sacar o agregar elementos) antes de pasarla a Flow.
- **[[Modulo 5 - Meta Ads (Anuncios)|Módulo 5]]:** Se usa con un prompt fijo para generar el copy del anuncio (texto principal, título y descripción) que después se adapta al ángulo de cada conjunto al duplicar una campaña ABO.

**Suele aparecer junto a:** [[Claude]] · [[Flow (Veo 3)]] · [[Gethookd]] · [[Higgsfield]] · [[Tiendanube]] · [[Canva]]
