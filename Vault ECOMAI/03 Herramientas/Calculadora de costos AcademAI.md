# Calculadora de costos AcademAI

App web (no Excel) para calcular la rentabilidad real de cada venta según condición fiscal: sugiere precio y margen de breakeven a partir del costo de producto, fulfillment, envío, impuestos y CPA objetivo, y también sirve para calcular el ROAS y CPA break-even antes de escalar una campaña.

🔗 https://calcuacademai.netlify.app/

## Para qué se usa en el curso

- **[[Modulo 2 - Busqueda de productos ganadores|Módulo 2]]:** App web (no Excel) para calcular la rentabilidad real por venta según condición fiscal, sugiriendo precios y margen de breakeven a partir del costo de producto, fulfillment, envío y CPA objetivo.
- **[[Modulo 5 - Meta Ads (Anuncios)|Módulo 5]]:** Se usa para calcular el ROAS y el CPA break-even reales de cada producto (descontando costo de producto, envío e impuestos) antes de decidir cuánto pujar en un escalado.

**Suele aparecer junto a:** [[Escalafy]] · [[Mercado Pago]] · [[Meta Ads]] · [[Shopify]] · [[Tiendanube]]
