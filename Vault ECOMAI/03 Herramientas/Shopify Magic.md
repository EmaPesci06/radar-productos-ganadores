# Shopify Magic

Función de IA integrada en el editor de temas de Shopify que puede generar directamente una sección o widget nuevo del sitio a partir de una instrucción de texto, sin escribir código.

🔗 https://help.shopify.com/en/manual/ai-powered-tools/shopify-magic
