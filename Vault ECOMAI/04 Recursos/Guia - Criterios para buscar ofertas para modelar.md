# Guia - Criterios para buscar ofertas para modelar

Lista corta de criterios para elegir qué oferta modelar en la Biblioteca de anuncios (cantidad y antigüedad de ads, tipo de marca) y qué significa modelar una oferta sin copiarla.

**Se usa en:** [[M8-03 Criterios para elegir una oferta a modelar|M8·3 Criterios para elegir una oferta a modelar]]

## Criterios para elegir una oferta

- Más de 20 ads corriendo.
- Corriendo ads hace más de 3 o 4 días.
- Que no sea una marca personal.
- Que venda un solo producto.

## ¿Qué quiere decir modelar?

Una vez que encuentro una oferta escalada, la pregunta es: ¿cómo puedo aumentar el valor percibido?

- Mejorar la estética.
- Mejorar la promesa de esa landing page.
- Crear nuestra PROPIA oferta más irresistible, no copiar y pegar.
- Adaptarme a los dolores que tiene, los problemas que soluciona, y mejorar la comunicación.
