## Resumen

Presenta la extensión Claude en Chrome, que le da a Claude visión y control del navegador para automatizar tareas de forma totalmente visual (saca capturas y actúa según lo que ve), a diferencia de una conexión por API donde la app le ofrece botones y parámetros ya definidos. Muestra dos ejemplos: crear una métrica personalizada en el admin de anuncios con un solo prompt, y analizar una página web completa de ecommerce para que Claude devuelva el avatar ideal del comprador.

## Puntos clave

- Se instala buscando Claude extension en Chrome, entrando a la oficial y agregándola [00:00]-[00:29].
- A diferencia de Claude Cowork, que se conecta por API y ejecuta acciones puntuales usando los parámetros que la propia app expone (ej. un botón Add Metric), Claude en Chrome funciona 100% visual: saca captura, lee lo que hay en pantalla y actúa, como si se le fueran mandando capturas una por una [02:05]-[03:20].
- Mientras trabaja, el mouse se mueve solo tomando el control del navegador; hay que dejarlo actuar sin interferir y mientras tanto se puede seguir trabajando en otra pestaña [02:55]-[04:46].
- Ejemplo de uso: crear una métrica personalizada de porcentaje de carritos (carritos agregados dividido clics salientes, en formato porcentaje) en el admin de anuncios con un solo prompt [01:02]-[02:05].
- Conviene primero pedirle a un LLM (Claude o ChatGPT) que arme el prompt específico para la extensión, detallando la tarea exacta a hacer [03:47]-[04:18].
- También sirve para analizar la página web completa de una tienda y pedirle, por ejemplo, el avatar ideal del comprador; el resultado se puede abrir directamente en Google Drive [06:05]-[07:30].
- No hace falta el plan Pro Max de Claude para usarla; funciona también con planes básicos [05:38].
- Es útil tanto para automatizar tareas repetitivas que uno ya sabe hacer como para aprender, porque muestra paso a paso lo que va haciendo [07:30]-[07:57].
