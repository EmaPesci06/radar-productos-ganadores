# Modulo 6 - Claude in ECOM

> [!abstract] 3 lecciones · ⏱ 15:13 de video

← [[Modulo 5 - Meta Ads (Anuncios)]] · [[00 - Inicio|↑ Inicio]] · [[Modulo 7 - Fiscal en ecommerce]] →

Este módulo muestra cómo conectar Claude directamente con las herramientas del día a día de un ecommerce para que ayude a analizar datos y automatizar tareas. Primero se arma un conector MCP personalizado para leer cuentas publicitarias de Meta Ads (mejores anuncios, CPA, frecuencia, ROAS) y después se conecta el conector nativo de Shopify para consultar pedidos, tickets promedio y necesidades de stock con bundles. Por último se instala la extensión Claude en Chrome, que funciona de forma visual, sacando capturas y actuando sobre lo que ve, para automatizar tareas repetitivas en el navegador como crear métricas personalizadas o analizar el avatar ideal de una landing. Al terminar el módulo vas a poder usar Claude como un analista y asistente operativo conectado a tus propias herramientas de venta.

## Lecciones

### 1. [[M6-01 Meta Ads con Claude|Meta Ads con Claude]] · 04:28

Explica cómo conectar Claude a Meta Ads mediante un conector MCP personalizado, ya que no existe una conexión directa oficial. Con el conector armado, Claude puede leer cuentas publicitarias individuales (no portafolios completos) y responder preguntas sobre el mejor anuncio, el CPA y la frecuencia de una cuenta puntual. También muestra cómo darle contexto de negocio (CPA y ROAS de equilibrio) para que identifique qué campañas están en pérdida.

### 2. [[M6-02 Analizar pedidos de Shopify con Claude|Analizar pedidos de Shopify con Claude]] · 02:43

Muestra que conectar Shopify a Claude es más simple que Meta Ads porque el conector ya viene por default (no hay que crearlo a mano). Con la tienda conectada, Claude puede responder preguntas sobre las últimas órdenes, como cuál fue el ticket más vendido y el avatar del comprador, o cuántas unidades conviene pedir de stock según cómo se venden los bundles.

### 3. [[M6-03 Automatizar tareas con Claude en Chrome|Automatizar tareas con Claude en Chrome]] · 08:00

Presenta la extensión Claude en Chrome, que le da a Claude visión y control del navegador para automatizar tareas de forma totalmente visual (saca capturas y actúa según lo que ve), a diferencia de una conexión por API donde la app le ofrece botones y parámetros ya definidos. Muestra dos ejemplos: crear una métrica personalizada en el admin de anuncios con un solo prompt, y analizar una página web completa de ecommerce para que Claude devuelva el avatar ideal del comprador.

## Notas

El video 3 menciona Claude Cowork solo como contraste (funciona por API con parámetros fijos, no de forma visual); no se desarrolla ni se usa en la clase, por eso no se lo incluyó como herramienta aparte.
