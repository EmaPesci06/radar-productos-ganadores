## Resumen

Segunda clase de Dylan Oviedo, donde muestra en detalle el flujo completo para armar un video animado con Flow a partir de un guion: primero le pasa a ChatGPT el prompt de reglas y estructura, después el guion completo (que la IA divide en clips, ajustables a pedido), y genera una imagen de referencia en estilo animado que sirve de base para todos los clips. Explica cómo usar el prompt de 'bloqueo de fondo' para que el fondo no cambie entre tomas, cómo encadenar clips usando el anterior como referencia para dar continuidad, y cómo corregir errores típicos (cambios de fondo, diálogo interpretado como acción visual) pidiéndole a la IA que 'blinde' el prompt.

## Puntos clave

- Flujo de trabajo: primero se le manda a ChatGPT el prompt de reglas y estructura, después el guion completo, y la IA lo divide automáticamente en clips (se le puede pedir que ajuste la cantidad, por ejemplo 'sumá el clip 5 al clip 4' para dejarlo en 4 clips) [00:50]
- Para el video animado primero se genera con ChatGPT una imagen de referencia en estilo animado (ejemplo del video: 'modelo Pixar'), cuidando que no quede 'excesiva' o poco agradable a la vista, porque esto aumenta la retención [04:32]
- Conviene generar de antemano 2 o 3 variantes de la imagen de referencia (ej. escena del problema, escena con el producto, escena final limpia) y subirlas todas juntas a Flow antes de decirle a ChatGPT que no genere más imágenes [06:39]
- Se usa el prompt 'animado con bloqueo de fondo' para que, al generar cada clip, el fondo no varíe ni se distorsione entre toma y toma [07:38]
- Antes de enviar cada clip hay que corroborar en ChatGPT que el diálogo coincide con lo que va a decir el guion, y ajustar la duración (6, 8 o 10 segundos) según lo que entre [08:37]
- Para dar continuidad entre clips conviene usar en Flow, además de la imagen, el video del clip anterior como referencia, aunque este tiene un límite de 6 segundos como referencia [10:53]
- Si un clip sale mal (ej. Flow cambia el fondo, o convierte literalmente en imagen una frase metafórica del diálogo), hay que 'blindar' el prompt aclarándole a ChatGPT que ninguna palabra del diálogo puede generar una acción visual [22:49]
- El prompt 'animado con bloqueo de fondo más transformación' se usa para los clips finales, donde el fondo pasa de un estado caótico a uno limpio de forma progresiva, con los personajes prácticamente fijos y cámara fija [27:46]
- A veces conviene generar el clip sin usar el video anterior como referencia (solo con la imagen) si la continuidad está afectando negativamente el resultado [16:59]
- Conviene revisar el diálogo completo de cada clip generado antes de pasar al siguiente, porque los errores de fondo o de sintaxis se acumulan si no se corrigen a tiempo [12:53]
