## Resumen

Tutorial corto para generar imágenes hiperrealistas de una persona usando el producto, sin necesidad de una sesión de fotos real. Se busca en Pinterest una foto de referencia de una persona que se parezca al buyer persona, se saca una captura del producto desde la tienda, y se le pasan ambas imágenes a Gemini (o ChatGPT) junto con un prompt específico para que genere una foto tipo selfie sosteniendo el producto. Cierra recomendando generar muchas variantes porque sirven tanto para redes como para la página web y para testear como creativos.

## Puntos clave

- Se busca en Pinterest una foto de referencia de una persona que se parezca al buyer persona (ejemplo del video: 'mujer de 50 años'), cuidando que se vean bien las manos [00:00]
- Se saca una captura de pantalla del producto (desde la tienda o donde esté publicado) para usarla como segunda imagen de referencia [00:42]
- En Gemini (o ChatGPT) se cargan las dos imágenes, persona y producto, junto con el prompt que pide una foto realista de la persona sosteniendo el producto en formato selfie [01:25]
- El formato de imagen se elige según el uso: 9:16 para celular, Instagram o stories, o 1080x1080 si es para un posteo [02:25]
- Recomienda generar muchas imágenes y ser creativo, porque sirven para todo: subir a Instagram, usar en la página web y testear como creativos publicitarios [03:04]
