## Resumen

Clase extensa que recorre los prompts encadenados para escribir el ebook completo con ChatGPT o Claude: nombre, índice, introducción, desarrollo de cada módulo y cierre con llamado a la acción, completando en cada uno el tema del ebook y a quién está dirigido. Muestra cómo ir copiando cada resultado a un bloc de notas en el orden correcto, y cierra mostrando cómo pegar todo ese texto en Gamma (plataforma de IA para maquetar documentos) para generar automáticamente el diseño y la estética del ebook eligiendo un tema de color acorde al nicho.

## Puntos clave

- Prompt de nombre: se completa con el tema del ebook y el objetivo/resultado que busca el cliente ideal; devuelve un listado de nombres posibles para elegir uno.
- Prompt de índice: con el tema y el público arma la estructura completa de módulos y una llamada a la acción final (ej. seguir en redes sociales).
- Prompt de introducción y prompt de desarrollo de cada módulo: se reutiliza el mismo prompt de desarrollo para cada módulo, sin necesidad de reenviarlo entero cada vez porque el chat recuerda el contexto [06:58].
- Prompt de cierre: arma la conclusión final del ebook con el mismo dato de tema.
- Orden correcto para pegar todo en el bloc de notas: título, índice, introducción, cada módulo en orden y por último el cierre con la llamada a la acción (no al final del índice).
- Para la estética se pega todo el texto en Gamma (corrección de 'Gama'), se separan las páginas con tres guiones donde se quiere un salto, se elige el idioma español latinoamérica y un tema de color acorde al nicho, y la IA arma el diseño completo del ebook.
- Una vez generado y aprobado el diseño en Gamma, se exporta desde el menú de los tres puntos.
