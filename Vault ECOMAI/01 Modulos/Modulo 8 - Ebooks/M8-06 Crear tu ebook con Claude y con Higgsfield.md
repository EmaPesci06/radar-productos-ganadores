## Resumen

Clase que muestra dos caminos para armar el ebook con Claude. El primero usa un prompt extenso que arma el ebook completo (texto) a partir de los datos del producto, sin imágenes. El segundo conecta Higgsfield a Claude como MCP y usa una skill entregada en el curso para que, a partir de un PDF de referencia y el link de la propia tienda (o de la competencia), Claude genere también las ilustraciones página por página y arme el PDF final.

## Puntos clave

- Primer camino: pasarle a Claude un prompt extenso que arma el ebook completo a partir de los datos del producto, sin generar imágenes.
- Conviene tener un plan pago de Claude, porque los créditos se gastan mucho más rápido con la versión gratuita.
- Segundo camino, con imágenes: conectar Higgsfield a Claude desde ajustes > conectores > añadir conector personalizado, pegando el link de MCP/CLI de Higgsfield y dejando el conector en 'permitir siempre'.
- Subir la skill de ebooks con Higgsfield entregada en el curso desde ajustes > skills > cargar una habilidad, y habilitar 'todos los dominios' en ajustes > capacidades (no solo gestores de paquetes) [01:03]-[01:39].
- Invocar la skill en un chat nuevo pasándole un PDF de referencia y el link de la propia tienda (o de la competencia, aclarando que el ebook se quiere en español) para que arme una primera muestra.
- Conviene pedir primero dos o tres imágenes de prueba, aprobar el estilo, y recién ahí pedirle que siga con el resto de las páginas indicando la cantidad total deseada.
- Una vez generadas todas las páginas en Higgsfield, seleccionarlas (no hace falta que estén en orden), descargarlas y pasárselas todas a Claude para que arme el PDF final ya ordenado.
