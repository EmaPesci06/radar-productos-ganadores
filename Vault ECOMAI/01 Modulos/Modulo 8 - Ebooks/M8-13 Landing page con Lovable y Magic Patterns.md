## Resumen

Clase que enseña a construir la landing con dos IAs generadoras de sitios, Lovable y Magic Patterns, a partir de un prompt que se completa con la sales letter (copy de venta) del producto y el link directo al carrito de Shopify. Explica paso a paso cómo obtener ese link de carrito (agregando .xml a la URL del producto para sacar el número de variante), muestra cómo queda la landing publicada en cada plataforma y advierte que pueden salir algo lentas, para lo cual entrega un prompt de optimización de velocidad. Cierra mostrando cómo cambiar a un tema gratuito de Shopify (Dawn) y ocultar el aviso de impuestos del checkout.

## Puntos clave

- El prompt de landing (uno para Lovable y otro equivalente para Magic Patterns) se completa con la sales letter y el link del carrito.
- Para sacar el link del carrito: copiar la URL del producto en Shopify, agregarle '.xml' en el navegador para encontrar el número de variante, y armar el link final con el dominio de la tienda más ese número.
- La sales letter a completar sigue la plantilla de copy de venta (promesa, dolores, solución, beneficios, qué incluye); se puede borrar cualquier sección que no se quiera usar, y hay un ejemplo de referencia ya completo.
- Al pegar el prompt completo, la IA arma toda la landing con los botones ya conectados al carrito; después se suben las imágenes propias (portada, bonos) indicando dónde colocarlas.
- Publicar da un link gratuito editable; para sacar la marca de agua de Lovable o Magic Patterns hay que pagar.
- Estas landings pueden quedar algo lentas por las animaciones, por eso se entrega un prompt aparte para mejorar la velocidad de carga sin cambiar nada visual.
- Para mejorar el checkout: cambiar el tema de Shopify al gratuito Dawn (corrección de 'Down'), publicarlo, y ocultar barra de anuncios, encabezado y pie de página desde el editor de tema.
- Para sacar el aviso de impuestos del carrito: en 'editar contenido predeterminado del tema' buscar 'taxes' y reemplazar el texto por algo como 'Acceso inmediato vía correo electrónico'.
