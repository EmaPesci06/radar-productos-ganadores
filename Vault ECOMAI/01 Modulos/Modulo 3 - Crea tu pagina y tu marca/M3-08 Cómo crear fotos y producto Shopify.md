## Resumen

Primera parte de la clase de creación de fotos de producto: David elige un producto de caída del cabello encontrado en una tienda de Estados Unidos para "replicarlo" en Argentina, y le pide primero a ChatGPT que analice toda la tienda de referencia (avatar, problema, promesa) antes de generar nombres de marca alternativos. Explica su criterio de herramientas: ChatGPT para armar los prompts de imagen porque Claude "se equivoca más" con imágenes, y Claude para el código Liquid. Muestra el flujo completo para cada foto: pasarle la imagen de referencia a ChatGPT para generar el prompt en español, pegar ese prompt junto con la foto original en Higgsfield AI para generar la nueva imagen, y cargarla en la ficha de Shopify con precio y categoría.

## Puntos clave

- Criterio de herramientas: ChatGPT para armar los prompts de imagen (Claude "se equivoca" más con imágenes), Claude para código Liquid [00:31]-[01:20]
- Primero le pide a ChatGPT que analice toda la tienda de referencia para que entienda el producto antes de generar nombres de marca alternativos [01:20]-[02:25]
- Higgsfield AI (plan de USD 250/mes por tokens) se usa para generar tanto las imágenes como los videos de producto a partir de un prompt y una foto de referencia [01:20]-[02:25]
- Flujo repetible por cada foto: copiar la imagen de referencia, pedirle a ChatGPT un prompt en español "limpio y profesional", pegar ese prompt y la foto en Higgsfield y generar [04:11]-[05:10]
- Conviene definir bien el nombre del producto (ej. "Capilux") antes de generar las imágenes, para no tener que rehacerlas si se cambia después [03:02]-[06:17]
- Al crear el producto en Shopify se carga precio (ej. $44.990), impuestos, precio de comparación, y se desactiva el inventario [07:03]-[07:36]
- Conviene ir preparando el prompt de la siguiente imagen mientras se genera la anterior, para no perder tiempo esperando; se pueden generar entre 7 y 10 imágenes por producto [07:36]-[09:53]
- Cuantas más fotos tenga el producto, más confianza transmite y más información recibe el cliente antes de comprar [11:08]
