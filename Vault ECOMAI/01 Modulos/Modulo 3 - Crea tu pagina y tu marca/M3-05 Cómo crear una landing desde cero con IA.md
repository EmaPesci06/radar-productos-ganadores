## Resumen

Última clase del módulo, donde Lucas enseña el método para armar una landing completamente nueva, sin replicar ninguna existente, usando tres prompts encadenados. Primero se completa un brief del producto (qué se vende, país, precio, ofertas), luego un prompt de investigación de mercado que propone ángulos de venta y estructura de landing, después un prompt que arma el copy de cada sección y el listado de fotos y videos necesarios, y finalmente un prompt que genera el código Liquid de la landing. Recuerda que la corrección de errores y la carga de imágenes se hacen igual que en la clase de réplicas.

## Puntos clave

- Paso 1: completar un brief del producto respondiendo qué se vende, en qué país, a qué precio y con qué ofertas [00:00]
- Paso 2: enviar el brief junto con el prompt 1 para que la IA investigue el mercado, el cliente objetivo y los competidores, y proponga ángulos de venta [00:52]
- De los ángulos de venta que devuelve la IA hay que elegir uno con criterio propio, apoyándose en la teoría de la clase de introducción [01:40]
- La IA también propone una estructura de landing sección por sección (objetivo, contenido, objeción que resuelve cada una); se analiza y se aprueba o se cambia [02:10]
- Paso 3: con el brief, el diagnóstico del prompt 1, el ángulo elegido y la estructura final aprobada se arma el prompt 2, que genera el copy de cada sección y la lista de fotos y videos necesarios [02:38]
- El prompt 3 pide brief, diagnóstico, ángulo, estructura final y copy plan, más referencias visuales opcionales (links o capturas) para copiarle la estética a secciones puntuales [04:53]
- El resultado del prompt 3 es el código Liquid de la landing, todavía sin imágenes ni videos cargados [05:50]
- Para cambiar los textos generados: seleccionar la sección, buscar con Ctrl+F el texto a reemplazar y editarlo directamente [06:21]
- Para corregir errores visuales se repite el mismo proceso de la clase de réplicas: capturar la pantalla (Win+Shift+S) y pedirle a la IA el cambio puntual [06:52]
