## Resumen

Video corto y práctico que muestra cómo sacar el Post ID (la identificación real de una publicación) de un anuncio ganador dentro de Meta Ads y por qué usarlo conserva todo el historial de aprendizaje del algoritmo, a diferencia de duplicar el anuncio, que solo copia el video sin ningún dato. Explica el paso a paso para copiarlo desde la vista previa del anuncio y pegarlo al crear un nuevo conjunto o campaña de renovación o escalado.

## Puntos clave

- Duplicar un anuncio (clic derecho > duplicar) solo copia el video; no trae las compras ni el historial que ya generó ese anuncio [00:00]-[00:28].
- Para sacar el Post ID: clic sobre el anuncio ganador → 'Abrir vista previa del anuncio' → flecha de arriba → 'Publicación de Facebook con comentarios'; el segundo número que aparece ahí es el Post ID [00:28]-[01:22].
- El Post ID sirve para renovar en base al ángulo ganador, ya sea armando otro conjunto dentro de la misma campaña o creando una campaña nueva, sin perder la información ya acumulada [01:22]-[02:47].
- Al armar el nuevo anuncio, en vez de 'Crear anuncio' hay que elegir 'Usar publicación existente' → 'Ingresar identificación de la publicación' y pegar ahí el Post ID [03:15]-[03:48].
- El resultado trae el video con toda su información real acumulada, listo para usarse tanto en campañas de renovación como de escalado [04:20]-[04:49].
