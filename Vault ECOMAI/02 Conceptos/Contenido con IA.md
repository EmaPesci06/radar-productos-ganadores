# Contenido con IA

Flujo de trabajo para generar videos publicitarios sin filmar: se le pasan a una IA de texto (ChatGPT o Claude) las reglas y la estructura de generación, se genera una imagen base por cada toma y se anima con herramientas de video con IA (como Flow/Veo 3).

## Qué dice el curso

- **[[Modulo 4 - Creativos publicitarios|Módulo 4]]:** El flujo de trabajo del módulo para generar videos publicitarios sin filmar: se le pasan a ChatGPT las reglas y la estructura de generación de imagen y video, se genera una imagen base por cada toma y se anima en Flow (Veo 3).
