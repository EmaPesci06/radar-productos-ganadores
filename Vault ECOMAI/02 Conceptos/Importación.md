# Importación

Traer productos desde el exterior (principalmente China, vía Alibaba) para venderlos en el mercado local. El curso la presenta como una forma de arrancar con proveedores propios, eligiendo línea de envío (idealmente DDP) y exigiendo pago protegido como Trade Assurance, aunque no la recomienda como la vía más barata para escalar.
