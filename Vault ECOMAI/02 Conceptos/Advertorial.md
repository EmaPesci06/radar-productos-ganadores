# Advertorial

Página o anuncio con formato de artículo informativo (no necesariamente una noticia falsa) que educa o genera intriga sin mostrar el producto de entrada. Se filtra en las herramientas espía como "page type = advertorial" y funciona bien para tráfico frío porque es fácil de replicar: solo requiere una imagen y un texto largo.

## Qué dice el curso

- **[[Modulo 2 - Busqueda de productos ganadores|Módulo 2]]:** Página o anuncio con formato de artículo informativo o pulireportaje (no siempre una 'noticia falsa' literal) que educa o genera intriga sin mostrar el producto de entrada. Se filtra en la herramienta espía por 'page type = advertorial' y es fácil de replicar porque solo requiere una imagen y un texto largo; funciona muy bien para tráfico frío.
