# Escalado

Subir el presupuesto y/o multiplicar los creativos y campañas de un anuncio que ya está funcionando para vender más. El curso trabaja varias formas: horizontal (multiplicar campañas y creativos ganadores), vertical (subir presupuesto), agresivo con BidCap, y por iteración de creativos (variar hook y cuerpo de un ganador), siempre comparando contra el CPA breakeven.

## Qué dice el curso

- **[[Modulo 1 - Pilares ecommerce|Módulo 1]]:** Subir el presupuesto de una campaña que ya está funcionando para vender más, sumando presupuesto y creativos; en el Video 2 también se usa para referirse a repetir el modelo de tienda replicada en más tiendas.
- **[[Modulo 4 - Creativos publicitarios|Módulo 4]]:** Se hace duplicando la campaña que funcionó (con creativos nuevos) y subiendo el presupuesto un 70% si hubo 5-6 ventas o el 100% si hubo más de 6, siempre comparando contra el CPA breakeven antes de seguir subiendo.
- **[[Modulo 5 - Meta Ads (Anuncios)|Módulo 5]]:** En este módulo se trabajan varias formas de escalado: horizontal (multiplicar campañas y creativos ganadores), vertical (subir presupuesto), agresivo con BidCap, y por iteración de creativos (variar hook y cuerpo de un ganador).
