# Código Liquid

Lenguaje de plantillas de Shopify en el que se pega el código que genera la IA (landing, secciones, carrito) dentro de bloques de "Liquid personalizado"; cada bloque tiene un límite de caracteres, por eso a veces una página se divide en varios Liquids.

## Qué dice el curso

- **[[Modulo 3 - Crea tu pagina y tu marca|Módulo 3]]:** Lenguaje de plantillas de Shopify en el que se pega el código que genera la IA (landing, secciones y carrito) dentro de bloques de "Liquid personalizado"; cada bloque tiene un límite de caracteres, por eso a veces una página se divide en varios Liquids.
