# ID de publicación

Identificador único (también llamado Post ID) que representa toda la información real que acumuló un anuncio publicado: compras, interacciones y el aprendizaje que ya hizo el algoritmo con él. Usar "Publicación existente" con este ID, en vez de duplicar el anuncio, conserva ese historial y es la forma correcta de renovar o escalar un anuncio ganador.

## Qué dice el curso

- **[[Modulo 5 - Meta Ads (Anuncios)|Módulo 5]]:** Identificador único (el segundo número que aparece al abrir la vista previa del anuncio como 'Publicación de Facebook con comentarios', también llamado Post ID) que representa toda la información real que acumuló un anuncio publicado: compras, interacciones y el aprendizaje que ya hizo el algoritmo con él. A diferencia de duplicar un anuncio, que solo copia el video, usar 'Publicación existente' con este ID conserva ese historial, y es la forma correcta de renovar o escalar un anuncio ganador.
