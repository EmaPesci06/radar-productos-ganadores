# Algoritmo

En Meta, el sistema (Andrómeda) que aprende mostrando cada creativo a distintas personas y midiendo su reacción (retención, minutos vistos, reacciones) para agrupar público que reacciona parecido y armar el "buyer persona" real a partir del comportamiento. En X (Twitter) es el sistema de recomendación de contenido, que el curso propone entrenar a propósito siguiendo cuentas de nicho para que muestre información cada vez más específica.

## Qué dice el curso

- **[[Modulo 5 - Meta Ads (Anuncios)|Módulo 5]]:** Andrómeda, el algoritmo de Meta, aprende mostrando cada video a personas y midiendo su reacción (retención, minutos vistos, reacciones) para ir agrupando público que reacciona parecido, y así arma el 'buyer persona' real a partir del comportamiento, no de datos declarados.
- **[[Modulo 9 - Algoritmo para ecommerce|Módulo 9]]:** En este módulo, el sistema de recomendación de contenido de X (Twitter) que se puede entrenar a propósito, siguiendo cuentas e interactuando de forma consistente con contenido de nicho, para que muestre cada vez información más específica y valiosa de ecommerce.
